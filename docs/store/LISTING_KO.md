# 깜짝! 스토어 등록 문구

Chrome Web Store와 Whale 스토어에 공통으로 사용할 한국어 등록 문구입니다. Whale의 상세 설명 입력란에는 아래 평문 내용을 그대로 사용합니다.

## 기본 정보

- 이름: 깜짝!
- 버전: 1.0.0
- 기본 언어: 한국어
- 권장 분류: 엔터테인먼트 또는 Fun
- 성인용 콘텐츠: 포함하지 않음

## 짧은 설명

한 시간마다 한 번씩 열어볼 수 있는 랜덤 상자 확장 프로그램입니다.

## 상세 설명

깜짝!은 한 시간마다 한 번, 무작위 결과 하나를 열어보는 브라우저 확장 프로그램입니다.

상자를 열면 일반 웹페이지에서 실행되는 짧은 시각 효과, 동물과 공룡 발견, 랜선 여행, 오늘의 TMI, 포춘 쿠키 등 16가지 현상 중 하나가 나타납니다. 결과는 Common, Rare, Epic, Legendary, Mythic 등급의 정해진 확률에 따라 선택됩니다.

나온 결과는 도감에 자동으로 기록됩니다. 발견한 현상과 하위 종류, 발견 횟수와 시각을 확인하고 다시 실행할 수 있습니다. 하위 종류가 있는 현상은 아직 나오지 않은 종류를 먼저 볼 수 있도록 설정할 수 있습니다.

주요 기능

- 한 시간마다 한 번 열 수 있는 무작위 결과
- 등급별 확률이 적용된 16가지 현상
- 발견 결과와 하위 종류를 기록하는 도감
- 발견한 현상 다시 보기
- 라이트 모드와 다크 모드
- 쿨타임 종료 브라우저 알림

깜짝!은 광고, 분석 도구, 추적 도구와 외부 네트워크 요청을 사용하지 않습니다. 발견 기록과 사용자 설정은 브라우저 안에만 저장되며 외부 서버로 전송되지 않습니다.

## Chrome 단일 목적

사용자가 한 시간마다 무작위 결과 하나를 열어 보고, 나온 결과를 도감에 기록하고 다시 확인할 수 있도록 합니다.

## 권한 사용 사유

### storage

도감의 발견 기록, 최근 결과, 다음 사용 가능 시각, 하위 종류 중복 방지 설정과 화면 테마를 브라우저에 저장하기 위해 사용합니다. 저장된 정보는 외부로 전송하지 않습니다.

### scripting

사용자가 상자를 열거나 도감에서 다시 보기를 눌렀을 때 선택된 시각 효과를 일반 웹페이지에 잠시 실행하기 위해 사용합니다. 삽입한 요소와 스타일은 효과가 끝나면 제거합니다.

### notifications

한 시간 쿨타임이 끝나 다시 상자를 열 수 있게 되었음을 브라우저 알림으로 알려주기 위해 사용합니다.

### alarms

브라우저가 백그라운드 상태여도 쿨타임 종료 시각에 알림을 요청하기 위해 사용합니다.

### host permissions: http://*/*, https://*/*

사용자가 기능을 실행한 일반 웹페이지에 선택된 시각 효과를 표시하기 위해 필요합니다. 탭 URL은 효과를 실행할 수 있는 페이지인지 확인하는 동안에만 사용하며 저장하거나 외부로 전송하지 않습니다. 브라우저 내부 페이지와 스토어 페이지에는 효과를 실행하지 않습니다.

## 원격 코드

원격 코드를 사용하지 않습니다. 모든 JavaScript, CSS, 이미지와 아이콘은 확장 프로그램 패키지에 포함되어 있습니다.

## 데이터 처리 요약

- 개인정보를 수집하지 않음
- 방문 기록, URL과 웹페이지 내용을 저장하지 않음
- 외부 서버 또는 제3자에게 데이터를 전송하지 않음
- 광고, 분석 및 추적 기능을 사용하지 않음
- 도감 기록과 설정만 사용자의 브라우저에 로컬 저장
- 탭 URL은 효과 실행 가능 여부 확인에만 일시적으로 사용

Chrome의 데이터 유형 선택 화면에서는 현재 구현 기준으로 외부에 수집하거나 전송하는 데이터 유형이 없습니다. 다만 등록 화면의 질문 문구가 변경되었거나 기기 내 처리까지 별도로 묻는 경우, 위 로컬 저장 및 URL 일시 처리 내용을 기준으로 답변을 다시 확인합니다.
